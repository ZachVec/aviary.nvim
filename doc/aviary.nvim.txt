*aviary.nvim*

aviary.nvim

Review Git changes and send references or text to agents displayed in Neovim.

  -----------------------------------------------------------------------
  Feature                             Use it for
  ----------------------------------- -----------------------------------
  hawk |hawk.nvim|                    Review Git versions.

  weaver |weaver.nvim|                Capture templates, file/buffer and
                                      line references, and selected text.

  pigeon |pigeon.nvim|                Create agents, display them in a
                                      Terminal, and deliver Messages.
  -----------------------------------------------------------------------

==============================================================================
1. Requirements                                     *aviary.nvim-requirements*

*pigeon.nvim-requirements*

- Neovim 0.11+; Git for Review.
- Pigeon: tmux 3.8+; Neovim must run inside tmux on the default socket.
- An installed agent CLI, such as Codex or Claude, to create its tool instance.
- `weaver.files()` and `weaver.buffers()` require snacks.nvim <https://github.com/folke/snacks.nvim>
    or fzf-lua <https://github.com/ibhagwan/fzf-lua>. Other choices use `vim.ui.select`.

2. Installation                                     *aviary.nvim-installation*

*pigeon.nvim-installation*

Install with lazy.nvim:

>lua
    {
      "ZachVec/aviary.nvim",
      main = "aviary",
      opts = {
        weaver = { picker = "snacks" }, -- snacks | fzf-lua; files/buffers only
      },
      keys = {
        { "<leader>ar", function() require("aviary").hawk.show() end, desc = "Review changes" },
        { "<leader>ac", function() require("aviary").weaver.prompt() end, mode = { "n", "x" }, desc = "Choose prompt" },
        { "<leader>af", function() require("aviary").weaver.files() end, desc = "Send file references" },
        { "<leader>ap", function() require("aviary").pigeon.show() end, desc = "Show agent" },
      },
    }
<

See the feature manuals above, or |hawk.nvim|, |weaver.nvim| and |pigeon.nvim|.
Use `pigeon.pick()` to choose an Agent or create a tool instance;
`pigeon.show()` reopens this editor’s Terminal and picks when no Agent is
attached. `<C-.>` hides it while the Agent keeps running. Select an Agent
before sending through Pigeon or Weaver. Each Neovim attaches its own client
directly to the chosen Agent session; sending uses that Terminal’s current
Agent. Agent exit closes attached Terminals naturally. See selection and
display |pigeon.nvim-exporting-and-selection| for configuration. Failed
requests warn once and are never automatically replayed.

Root setup accepts public feature names; nested tables belong to their feature.
Each call rebuilds from feature defaults and the current options. Previously
root-configured features omitted from the call also reset to defaults;
`setup()` and `setup({})` reset all such features. Features never configured
through root are left untouched. Calling `aviary.<feature>.setup(opts)`
directly rebuilds only that feature. Modules load lazily by name. Setup
validates data and acquires no runtime resources.

3. Workflows                                           *aviary.nvim-workflows*

Weaver actions |weaver.nvim-usage| capture content and send it through
Pigeon’s current Agent; Hawk |hawk.nvim| opens Git Review:

>lua
    local aviary = require("aviary")
    aviary.pigeon.pick()    -- choose/create an Agent before using Weaver
    aviary.weaver.prompt()  -- choose a template; {line} uses the cursor line or Visual range
    aviary.weaver.files()   -- choose file references and send them
    aviary.weaver.buffers() -- choose buffer references and send them
    aviary.weaver.text()    -- send the active Visual lines or cursor line
    aviary.hawk.show()      -- inspect changed files and two Git versions
<

All actions take no arguments and return nothing. Text capture delivers
immediately; selectors deliver after confirmation. Prompt context, including
any Visual range, is captured before template selection. Resuming a file/buffer
picker can send again. Cancellation sends nothing. `hawk.show()` opens or
focuses its single reusable Review tab. Review defaults to HEAD → index,
following HEAD on refresh; Enter displays the selected file’s captured
versions in native diff. b/B and f/F choose refs/commits, and t toggles
merge-base comparison. Creation errors propagate after rollback. Asynchronous
Review failures report once and leave the UI available for retry.

Choose the `{line}` prompt for the current file and cursor line or Visual
range. This replaces the former Hawk comment action; there is no comment input
or stored comment list. Setup configuration stays under feature names.

4. Default Options                               *aviary.nvim-default-options*

Default Options ~

>lua
    require("aviary").setup({
      hawk = {
        keymaps = {
          close = { "q" }, refresh = { "r" }, jump = { "<CR>" },
          base_ref = { "b" }, base_commit = { "B" },
          target_ref = { "f" }, target_commit = { "F" }, toggle = { "t" },
        },
        actions = {}, -- handlers receive the owning Review Tab
      },
      weaver = {
        picker = "snacks",
        prompts = { ["{file}"] = "{file} ", ["{line}"] = "{line} " },
        resolvers = {}, -- merges over built-in file/line resolvers
        references = { join = "\n" },
      },
      pigeon = {
        format = function(path, first, last)
          if not first then return path end
          return path .. " :L" .. first .. (last and last ~= first and "-" .. last or "")
        end,
        tools = {
          codex = { command = { "codex" } }, -- uses pigeon.format
          claude = {
            command = { "claude" },
            format = function(path, first, last)
              local mention = path:find("[^%w/_%.%-]") and ('"' .. path .. '"') or path
              return "@" .. mention .. (first and "#L" .. first or "")
                .. (first and last and last ~= first and "-" .. last or "")
            end,
          },
        },
        keymaps = { close = { "<C-.>" } },
        actions = {}, -- the built-in close closes the current window
        view = { width = 0.9, height = 0.9, border = "rounded" },
      },
    })
<
