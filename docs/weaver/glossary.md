# Weaver glossary

| Term | Meaning |
| --- | --- |
| Resolver | A configured function mapping a captured Selection to a Message for one placeholder occurrence in the chosen template. |
| Selection | The source filename and inclusive whole-line range captured before template selection: the cursor line in Normal mode, or the selected rows in Visual mode. |

Capture and expansion contracts live in the
[module entry](../../lua/aviary/weaver/init.lua) and [manual](../weaver.md#templates).

Message is defined in the [shared Message glossary](../shared/message/glossary.md).
